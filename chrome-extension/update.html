Update your extension

Installed version:

This is a manually installed extension. To get the latest changes, replace its local files and reload it.

  1. Open Notification Manager on GitHub and choose Code → Download ZIP.
  2. Extract the ZIP. Inside it, open the chrome-extension folder.
  3. Copy that folder’s contents into the same chrome-extension folder you originally installed, replacing the old files. Keep the installed folder in its current location.
  4. Open Chrome’s extensions page with the button below. Leave Developer mode enabled.
  5. On the Notification Manager card, click Reload (the circular arrow). Its window will refresh with the updated code.

Chrome’s page-wide Update button checks store releases; it does not download this extension’s code from GitHub. Reload loads the files you have copied.

Keep the existing installation instead of removing it to preserve local preferences. Let any pending move or dismissal finish before reloading.

Installing on another laptop?

Download and extract the same GitHub ZIP. Move the extracted folder to a permanent location, then open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the chrome-extension folder that contains manifest.json.

Use the Chrome profile for the same Google account as your phone. Open Notification Manager and connect Google. Dismissals and recent move history sync through Drive; local preferences must be set again.
