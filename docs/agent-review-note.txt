Recent work to inspect:

1. Dismissal sync now uses independent immutable Drive appData markers plus a local-first cache and retry. The old shared JSON file is read only. Concurrent clients should preserve the union of dismissals. A future event dismissal should remain dismissed. Recurring series display individual instances, and dismissal applies to one instance; moves of recurring events are blocked both in UI and in Calendar request code.
2. Sync status distinguishes Calendar refresh, dismissal sync, local pending changes, stale state, and failure. API success determines whether state is actually synced; network transport is only a hint. The old general Recent actions log was removed. The settings menu now has compact Sync, Window, Recent dismissals, and Events recently moved entries.
3. The Android home-screen widget supports scrolling, app-style event expansion, direct move/dismiss with Undo, and Wi-Fi-only hourly refresh when the last successful Calendar refresh was at least 59 minutes ago. Search and calendar picking open the app.
4. Recent dismissals shows up to ten event titles. New dismissals store titles in Drive marker metadata. Old titleless entries can resolve from local cache or a read-only Calendar lookup.
5. New recent-move history saves minimal records locally and syncs independent Drive appData markers. It records only after a confirmed Calendar update, keeps the newest ten records and excludes records older than 30 days, and retries local records after Drive failures. Android app, widget, and Chrome extension can all create records. Older moves cannot be reconstructed. Verify concurrent clients, duplicate retries, pruning, malformed/partial markers, write failures, account isolation, and that a history failure never reports a successful Calendar move as failed.
6. The Chrome extension action ribbon now opens directly above its own event instead of choosing above or below or covering the title. The first event's ribbon may cover the header. Verify hover travel from the three-dot button to every tile, click and keyboard behavior, zoom/short windows, and whether list scrolling or pointer movement causes the ribbon to disappear or jump.
